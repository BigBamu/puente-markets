# Publicera Puente Markets på mobilen

## Snabbaste vägen

1. Packa upp ZIP-filen på en dator.
2. Skapa ett privat projekt på GitHub och ladda upp mappen.
3. Importera projektet på Vercel.
4. Välj **Other** som framework och lämna build command tom.
5. Publicera.
6. Öppna länken på iPhone i Safari.
7. Tryck på delningsikonen och välj **Lägg till på hemskärmen**.

## Notiser

MVP:n kan ge webbläsarnotiser medan appen är aktiv. För riktiga pushnotiser när appen är helt stängd behövs nästa fas med databas, Web Push-prenumeration och en schemalagd serverfunktion.
