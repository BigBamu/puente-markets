# Puente Markets v0.2

Privat, mobilanpassad PWA för att läsa fotbollsmarknader på Polymarket och testa en virtuell portfölj. Appen placerar inte riktiga bets eller ordrar.

## Vercel

Projektet är byggt för Vercel som en statisk webbapp med serverless API-funktioner i `/api`.

1. Ersätt alla gamla filer i GitHub-repot med innehållet i denna mapp.
2. Vercel gör automatiskt en ny deployment.
3. Öppna deployment-länken när status är Ready.

## Lokalt

Öppna med en enkel statisk webbserver. API-rutterna fungerar endast på Vercel eller med Vercel CLI.
