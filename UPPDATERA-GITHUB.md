# Uppdatera den kraschade Vercel-versionen

1. Packa upp ZIP-filen.
2. Öppna GitHub-repot `puente-markets`.
3. Radera de gamla filerna `server.mjs` och den gamla `package.json` först.
4. Välj **Add file → Upload files**.
5. Dra in allt innehåll från den nya mappen.
6. Klicka **Commit changes**.
7. Vercel startar automatiskt en ny deployment.
8. Öppna Vercel → Puente Markets → Deployments och vänta tills den senaste står **Ready**.
